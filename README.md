# EcoVerse — Interactive 3D Ecosystem

An interactive 3D website about Earth's eco-friendly ecosystem: a spinning Three.js planet with procedural continents, clouds, atmosphere glow, orbiting particles, floating leaves and a satellite — plus ecosystem pillars, planet stats, a carbon footprint calculator and eco habits.

**Live on Vercel:** https://ecoverse.vercel.app

## Features

- **3D Earth** (Three.js r128, vendored in `js/three.min.js` — works offline): drag to spin, mouse parallax, procedural texture, clouds, atmosphere shader, orbit ring + satellite
- **Ecosystem pillars**: Forest, Ocean, Clean Air, Renewable Energy — 3D tilt cards
- **Planet stats**: animated counters with real approximate figures
- **Carbon footprint calculator**: driving, flights, electricity, diet → tonnes CO₂/year + trees needed to offset, with a visual comparison against the 4.7 t global average
- **Eco habits**: six everyday actions with their savings
- Scroll progress bar, scroll-reveal animations, responsive (mobile + desktop), reduced-motion support

## Run locally

Open `index.html` in a browser (or serve the folder with any static server).
